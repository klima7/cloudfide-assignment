# Cloudfide assignment

Assignment text is contained inside `task.pdf`. `solution.py` is the solution.

## Environment setup
- Install [uv](https://docs.astral.sh/uv/getting-started/installation/) if it is not already on your PATH
- Create the virtual environment and install dependencies:

```bash
uv sync
```

## Run tests
- Execute the test suite with:

```bash
uv run pytest
```
